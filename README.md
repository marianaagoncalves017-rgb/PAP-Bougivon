# 🕯️ Bougivon — Loja Online de Velas Artesanais

Projeto de Aptidão Profissional (PAP) 
Aluna: Mariana Gonçalves  
Curso: Técnico de Gestão e Programação de Sistemas Informáticos  

# 📌 Sobre o Projeto
O Bougivon é uma plataforma e-commerce desenvolvida para a venda de velas e produtos artesanais. O sistema permite aos utilizadores navegar pelo catálogo de produtos, gerir o carrinho de compras e simular pagamentos (incluindo temporizador MB WAY).

# 🛠️ Tecnologias Utilizadas
Frontend: HTML5, CSS3, JavaScript
Backend: PHP
Base de Dados: MySQL
Alojamento Web: InfinityFree
